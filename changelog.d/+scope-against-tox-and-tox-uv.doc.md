The README now says what this plugin does *not* do. `tox`'s own `pylock` option and `tox-uv`'s `uv-venv-lock-runner` both install from a lock; neither writes one and neither reports a stale one, and `uv sync` covers a single project-level `uv.lock` rather than the several dependency sets a repository's linters, type checker and release tooling each pin separately. A new Scope section draws that boundary and says which of the two each output format is meant to be handed to.
