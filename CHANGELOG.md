# Changelog

All notable changes to `tox-lock` are recorded here. Each entry is
written when the change is made, as a file under `changelog.d/`, and
collected into a section below when a version is cut -- see
[`changelog.d/README.md`](changelog.d/README.md).

The section for a released version is also what
`.github/workflows/release.yml` publishes as that release's notes, so
what is written below is what users read on the release page.
